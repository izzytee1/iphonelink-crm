# iPhoneLink React v02 — Features

- 14-column Leads grid transcribed from supplied iPhoneLink HTML.
- 10 source mock leads, search, filter, inline details, column-resizing, local Add Lead.
- Compact statistics calculated only from matching tracked activity where available; unavailable counts show a dash.
- Fixed bottom-edge horizontally draggable Communications launcher, shared Email mailbox.
- Gmail-like sidebar, clear outlined folder icons, search and advanced filters, full-width reading view.
- Email reading, selection, moving, archive, spam, trash, unread actions, reply, reply all, forward.
- Compose: account selection, To, Cc, Bcc, subject, rich editor, templates, attachments, tracking toggle, draft autosave, minimize, maximize, undo local send.
- No Snoozed, Important, custom labels, Print or Schedule Send. No Star/Important row icons.
- Real mail-server integration not included.
