# iPhoneLink React v03 — Features

- Preserved CRM Leads workspace, fourteen columns, ten mock leads and email functionality.
- Completely rebuilt Communications panel with All, Messages, Calls and Email.
- Movable bottom launcher; adaptive panel for phone and desktop.
- Calls: Recents, Contacts, Call detail and standalone keypad inside Communications only.
- One shared phone controller for call state and number input.
- Accurate two-frequency DTMF sounds and provider signaling when available.
- SMS and WhatsApp conversation views, local drafts, unread-state updates.
- Connected browser-local mailbox viewer with open, mark read and compose through the existing Email page.
- Subtle press and click sound across CRM buttons; no greyed-out actions.
- Deleted original Communications UI code and topbar dialer rather than hiding them.
- Live SMS/WhatsApp sending and live call management require external service providers.
